# Animated Login/Register UI

A modern and responsive Login/Register user interface built using HTML and CSS. This project features glassmorphism effects, smooth animations, responsive layouts, and a clean user experience.

## 🚀 Features

- Modern Glassmorphism Design
- Animated Background Effects
- Responsive Layout
- Login Form UI
- Register Link Section
- Smooth Hover Effects
- CSS Animations
- Mobile Friendly Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
